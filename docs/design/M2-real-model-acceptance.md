## 执行与额度边界

- 服务：用户在了解十题内容后提供了新服务、key 与模型；本轮按切换并执行该十题理解，改用 `https://xfastapi.ai/v1`、`gpt-6.1-sol`，取代先前拟用的 OpenCode Go。凭据仅后端读取，不复制到文档、日志、浏览器或 Git。2026-11-14 调度只读查询 `/v1/models` 得 HTTP 200 且模型存在；尚未用对话请求验证工具调用能力。
- 本轮执行范围：最多十个真实修改任务，串行执行，不自动重试、不补跑失败任务；每任务沿用现有最多 16 轮、180 秒总时限。因此十任务不等于十次模型请求，极限是 160 轮调用，实际数量逐条记录。没有可靠单价/用量上限依据，不预报固定费用。这不构成其他服务或未来补跑的无限额度授权。
- 使用独立作品副本和数据目录，代码来自冻结实现；每题都恢复同一干净基线、重新点选并取作品版本。复用已验证的逐包真实依赖链接方法，不将整个 node_modules 目录做 junction，也不替换被主线 Vite 监视的 src。
- 经 Studio 的实际点选、提交、候选预览、采用、回退路径验收；不直接把期望源码写入候选。模型仅得固定指令与正常选择上下文，Pi 的预期断言不作为附加提示发送。
- 成功题采用至隔离作品，确认生效后回退，验证源码与场景恢复；失败题撤回候选。真实主作品、当前 scene.config.json 和已有历史不变。
- 只允许编码服务的必要 HTTPS 出站，Lux3D 仍指向不可用 loopback/mock，不允许产生真实 3D 任务。测试 launcher 不继承无关凭据；不能因网络守卫不支持所需域名而关闭全部保护。
- 环境无法启动/密钥无效等在首个真实任务提交前停止，记为验收未开始。首个任务开始后固定完成十个结果；超时、上游故障、任务失败、无候选或候选错误均计失败，不能剔除后重试。出现越权写入或凭据泄露立即安全停止，M2 不通过；未完成十题不能报达到成功率。

## 每题通用通过条件

1. 后端任务在现有预算内产出真实模型生成的候选，候选网页加载成功，无新增未捕获脚本异常；表中目标断言全部成立。
2. 候选采用前，当前作品保持基线；采用后隔离作品有预期效果；回退后恢复基线。不允许 Pi 手动补改模型代码后算成功。
3. 保留源码标记/bridge、三个按钮、三条卖点、3D 加载与滚动开盖。非本题允许范围内的可观察行为/内容变化计失败，不能以“看起来差不多”放过。
4. 工具不可越出允许路径、不改依赖/配置权限边界、不泄露密钥；越界提示应如实展示。CSS 文件可能按既定文件级规则列入 outOfScope，提示本身不等于失败；实际改动仍必须符合本题指令。
5. 候选内建四项自动检查仍显示 `not_run`/“未检查”；Pi 的验收观测独立记录，不能把 M3 尚未实现的检查标为通过。
