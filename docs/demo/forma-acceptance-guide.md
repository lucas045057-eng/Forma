# Forma 空间工作台 · 人工操作验收指南

本指南用于人工端到端检验 **Forma 空间工作台** 的核心能力：**真实大模型连接**、**无模板限制自由创建网页（2D/3D）**、**把已有网页拉进工作台局部精修**、**拖入/插入 3D 空间模块** 以及 **质量门禁与版本回退**。

---

## 0. 启动与环境确认（约 15 秒）

1. 确保 `apps/server/.env` 已配置真实模型凭据（编码模型、百炼语音、Lux3D；切勿将 `.env` 提交入库）。
2. 在仓库根目录一键启动 Forma：
   ```powershell
   pnpm forma
   ```
   - 终端输出示例：`Forma Studio=http://127.0.0.1:5173; workspace=E:\空间化AI工作台\.data\forma`
   - 所有创建或导入的作品均自动持久化在 `.data/forma`（如需一次性空白隔离环境可加 `--ephemeral`）。
3. 浏览器打开 `http://127.0.0.1:5173`：
   - **预期**：左上角显示 **`FORMA · Forma 空间工作台`**，状态胶囊依次显示 **`预览已连接`**、**`事件已连接`**、**`真实模型 · <模型名>`**（悬停可查看编码、语音、Lux3D 三项服务连接状态）。

---

## 1. 链路一：自由创建现代网页（纯 2D 交互网页，无固定模板束缚）

1. 点击画布工具栏左侧的 **`+ 新建网页`**。
2. 在弹窗保持 **`✦ 自由现代网页`** 选中：
   - **作品名称**：输入 `极简建筑设计工作室`（或留空自动命名）。
   - **一句话描述**：点击灵感标签，或输入：
     > `做一个北欧极简建筑事务所官网，包含大标题、三个可切换的代表项目卡片，以及点击后显示预约成功提示的咨询按钮`
3. 点击 **`创建并由 AI 生成网页`**。
4. 观察右侧任务卡片实时展示真实大模型调用步骤（`list_files` → `read_file` → `write_file` → `finish`），直至状态变为 **`候选已就绪`**（如弹出范围外/全局样式请示卡片，点击 **`批准本次修改`**）。
5. 在画布下方候选区点击 **`运行检查`**：
   - **预期**：`场景配置`、`构建`、`页面冒烟`、`交互遮挡` 四项检查全部显示 **通过**，六份检查证据自动校验通过，右上角 **`采用此候选`** 按钮亮起。
6. 点击 **`采用此候选`**：
   - **预期**：新网页正式合入当前作品，在左侧预览中直接点击项目切换卡片与咨询按钮，交互反馈正常。

---

## 2. 链路二：一句话创建 3D 空间网页 + 3D 场景编辑

1. （准备模型）点击顶栏 **`3D 资产`**：
   - 可在上方通过 **图生 3D / 文生 3D** 生成新模型，或在下方 **本地备用资产** 点击 **`导入备用`** 快速准备一个就绪 `.glb` 模型，随后点击 **`返回网页`**。
2. 点击 **`+ 新建网页`** → 选择 **`◈ 3D 空间网页`**：
   - 在 **初始主舞台 3D 模型** 下拉框中选择刚就绪的 3D 模型。
   - 输入描述：
     > `做一个曜石黑无线 HiFi 音箱的空间新品发布页，保留三维主舞台，加入声学工艺介绍与预约试听按钮`
   - 点击 **`创建并由 AI 生成网页`**。
3. 待候选就绪后依次点击 **`运行检查`** → **`采用此候选`**。
4. 点击顶栏 **`3D 场景编辑`**：
   - **预期**：调节主舞台旋转、缩放或环境光/主光强度并点击保存，左侧网页中的实时 WebGL 3D 舞台立即同步生效；也支持一键撤回场景参数。

---

## 3. 链路三：把已有网页拉进 Forma + 指着说局部修改

1. 点击画布工具栏的 **`⤓ 导入网页`**（或 `+ 新建网页` 切换到 **`⤓ 拉入已有网页修改`** 标签页），任选以下四种方式之一拉入已有网页：
   - **上传文件 / 文件夹**：直接拖入本机 `.html + .css + 图片` 文件夹，或已有 React `src/App.tsx` 项目文件夹。
   - **粘贴 HTML 源码**：粘贴任意现有 HTML 代码（也可点击 **`填入示例网页源码`** 一键填入测试页）。
   - **输入网址 URL**：输入公网 `https://...` 页面地址自动抓取并离线本地化。
   - **本机目录路径**：输入本机绝对目录路径（如 `D:\my-site`）。
2. 点击 **`拉入 Forma 工作台`**：
   - **预期**：外部网页立即出现在左侧主预览中，作品切换下拉框新增 **`<作品名> · 已导入网页`**。
3. **指着说精准修改**：
   - 点击顶栏 **`开启选取`**，鼠标移入左侧刚导入的网页，任意标题、段落、按钮均出现高亮选框。
   - 点击页面主标题（右侧 `TARGET` 卡片会显示命中的源码行号 `src/App.tsx:行:列`）。
   - 在右侧输入框输入（或按住 **`按住说话 / 空格`** 语音输入后确认）：
     > `把这个主标题改成更有东方意境的表达，并在下方增加一句简短副标题`
   - 点击 **`生成候选版本`** → 如出现请示卡点击 **`批准本次修改`** → **`运行检查`** → **`采用此候选`**。
   - **预期**：外部导入网页的对应区块被精准修改并上线。

---

## 4. 链路四：向已有网页拖入/放入 3D 模块 + 多作品切换与回退

1. 在刚导入或新建的网页上，点击顶栏 **`3D 资产`** → 选择一个就绪模型 → 点击 **`放入网页`**。
2. **添加独立 3D 模块（或替换已有 3D 槽位）**：
   - 按住左侧浮动卡片上的拖动手柄拖入网页中的任意区块（或直接点击网页中的某个卡片/`<section>` 区块；若点击的是已有 3D 舞台/模块，则自动切换为替换模式）。
   - 在左侧放置确认栏可调整宽度百分比、缩放与旋转角（如模型超门槛勾选强制采用），点击 **`确认放置`**。
3. 在右侧请示卡点击 **`批准候选`**（或 **`批准本次修改`**）→ 下方候选区点击 **`运行检查`** → 四项检查通过后点击 **`采用此候选`**：
   - **预期**：原 2D 网页的指定区块内成功嵌入可交互的独立 WebGL 3D 模块。
4. **一键回退与多作品切换验证**：
   - 点击画布工具栏的 **`回退上一次采用`**：刚插入的 3D 模块（或上一次修改）立即干净撤回，更早的历史修改完整保留。
   - 通过左上角 **作品下拉框** 在多个作品之间自由切换，确认每个作品的页面内容、3D 场景和版本历史完全独立且重启不丢失。
