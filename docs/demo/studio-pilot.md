# Forma 空间画布试用指南

这轮试用从创建一个咖啡品牌主页开始。完成后，重开工作台，继续编辑自己采用的那个版本。

## 启动

在仓库根目录使用 Node 24 和 pnpm 11.17.0。首次准备开发环境时运行以下命令。

```powershell
pnpm install --frozen-lockfile
pnpm exec playwright install chromium
```

运行 `pnpm forma`，打开终端打印的 Studio 地址，同时记下同一行的 `workspace` 路径。默认地址为 `http://127.0.0.1:5173`，端口已占用时，启动程序会另选一个。首次配置网页生成时，在 `apps/server/.env` 填写 `CODING_AGENT_BASE_URL`、`CODING_AGENT_MODEL` 和 `CODING_AGENT_API_KEY` 后重启。试用 3D 可以选已有的就绪资产。

要把试用作品和日常作品分开保存，可在 PowerShell 中用以下命令启动。下次继续试用时，使用同一目录。

```powershell
$env:FORMA_DATA_DIR = Join-Path $PWD '.data/studio-pilot'
$env:FORMA_PORT = '5183'
pnpm forma
```

## 走一遍创作流程

1. 点击 **新建网页**，选择 **独立咖啡馆品牌主页**，给作品起一个容易认出的名字。点击 **创建并由 AI 生成网页**。候选就绪后，运行检查并采用首版。
2. 点击 **开启选取**，点一下预览里的咖啡馆标题。在右侧要求把它改为“周末手冲计划”，点击 **生成候选版本**。如果出现修改范围请示，核对范围后批准。
3. 点击 **并排对比**，找出旧标题和新标题。运行检查，四项通过且预览符合预期后，点击 **采用此候选**。
4. 关闭并重开页面，从作品下拉框选回刚才命名的作品。确认标题还在，再点选它继续编辑。要验证服务重启后的恢复，可在启动终端按 Ctrl+C，再用同一工作目录和数据目录启动。

第一轮可请两三位首次使用的人各自走完这四步，观察他们能否独立认出采用的版本并再次找到它。请记录哪一步需要别人解释，以及哪一步界面提示成功但画面与预期不符。反馈时附上操作、预期、实际结果和候选编号即可。

## 重开作品与回退

- 常规启动把作品保存在 `.data/forma`。使用过自定义目录时，重新设置 `FORMA_DATA_DIR` 为原先打印的完整 `workspace` 路径。`--ephemeral` 每次启动都会新建目录。要重开以前的作品，把 `FORMA_DATA_DIR` 指向那次打印的目录，再运行普通的 `pnpm forma`。
- **撤回候选** 会关闭尚未采用的草稿。**回退上一次采用** 会把当前作品恢复到该次采用之前的版本。重开已有作品只需选择作品名称。在旧版已检查、尚未采用的候选，升级后需要重新运行检查。

## 这版的 3D 放置范围

选择就绪资产，点击 **放入网页**，再点插图外层的网页区块，可以插入独立的 3D 模块。普通 2D 插图的原位替换留到下一版。若误把模型放进 SVG 插图内部，页面冒烟检查会拦住候选，并提示重新选择外层区块。

检查会等待已挂载的模型加载，并检查画布是否有可见面积。被父容器完全裁掉的画布会报错，向下滚动就能看到的模型可以通过。其他元素是否盖住了模型、位置和构图是否合适，请在候选预览中目测。跨预览框的拖放仍有自动化测试限制，同一条放置流程也可通过点击区块体验。
