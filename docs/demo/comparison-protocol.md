# 非程序员 A/B 对照协议与空白记录

状态：材料已编写，招募/真人实验/统计均未执行。不得用代理、自动化、虚构参与者或mock转写成绩代替真人结果；不自动联系或招募任何人。

## 方法

3–5名非程序员参与；仅记录匿名编号，不记录姓名、联系方式或秘密。A为聊天+预览流程，B为本空间化工作台。双方从同一香薰模板、同一素材、相同任务说明开始；每人交替AB或BA顺序，分配尽量平衡，记录实际顺序。提前给等量熟悉时间，熟悉任务不计入正式成绩。A/B如使用不同真实模型或语音服务，必须记录差异，不能把工具差异归因成界面因果。

三任务：移动购买区；修改标题并撤回未采用候选；修改共享按钮圆角并核对三个实例（B含请示/真实检查/明确采用，A也要独立检查最终结果）。固定目标与验收文字，不能因某组困难临时换题。每次新隔离副本，不复用上一次结果。

计时从读完任务到参与者声明完成或中止；完整记录尝试轮数、错误改动、取消/失败、人工帮助和难度1–5。失败也占样本，不删除后补一个成功。中止阈值与帮助规则需正式执行前双方固定，空白项不是默认成功。只有实际参与者确认体验评分才填主观分。

## 分析规则

分别报告A/B的真实完成率、耗时中位数与范围、轮数、误改、评分和失败案例；保持同一参与者配对，不将未执行当0秒。原始记录保留且说明缺失值。3–5人只作方向性描述，不宣称普遍提升或统计显著；没有数据时不填写提升百分比。真实语音、mock、文字降级与备用模型必须分列，不能混合成统一“真实完成率”。
